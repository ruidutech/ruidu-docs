# 企业管理

「企业管理」维护企业信息、成员、邀请和入驻申请。仅**所有者**和**管理员**可见（在顶部用户菜单中进入）。企业的概念参见 [快速开始](./quick-start)。

![](/images/orbitcontrol/user-guide/mgr-tenant-page-main.png)

## 成员管理

成员列表展示所有企业成员（用户、角色、加入时间）：

- 角色徽标：👑 所有者 / 🛡 管理员 / 成员
- **所有者**可移除成员（不可移除自己）
- 一个账号可加入多个企业，成员在顶部菜单中切换当前企业

## 邀请链接

生成邀请链接邀请新成员：

![](/images/orbitcontrol/user-guide/mgr-tenant-panel-invite.png)

- 邀请链接格式 `https://<平台地址>/join?code=<邀请码>`，可一键复制发送给被邀请人
- 邀请码 **8 位**，有效期 **72 小时**，最多使用 **10 次**
- 显示已使用次数和创建时间，可随时「重新生成」（旧链接失效）

被邀请人打开链接（或直接输入邀请码）提交申请，见 [快速开始](./quick-start)。

## 入驻申请

使用邀请码申请加入的用户出现在「入驻申请」列表（页签上显示待处理数量角标），管理员逐条**接受**或**拒绝**；接受后申请人即成为企业成员。

## 转让所有权（仅所有者）

所有者可将企业转让给其他**管理员**：转让后新所有者获得全部权限，原所有者变为管理员。列表中没有管理员时，需先将成员提升为管理员。
