# 用户管理

「用户管理」维护系统内的用户账号，可查看账号信息并启用/禁用账号。用户的角色与站点权限在 [企业管理](./tenant) 和 [站点管理](./sites) 中分配。

## 用户列表

![](/images/orbitcontrol/user-guide/mgr-users-page-list.png)

表格展示所有用户，支持按用户名或邮箱搜索、分页：

| 列 | 说明 |
|----|------|
| 用户名 | 当前登录用户带「当前用户」标记 |
| 邮箱 | 注册邮箱 |
| 姓名 | 用户全名 |
| 状态 | 活跃 / 已禁用 |
| 创建时间 | 账号创建时间 |

## 启用/禁用账号

- 点击操作列的电源按钮**禁用**账号：被禁用的用户无法登录系统
- 再次点击**启用**恢复
- 出于安全考虑，不能禁用当前登录的账号
