# 运行日志

「运行日志」记录每一次任务执行的完整信息：谁在何时执行了什么任务、运行数据如何、产出了哪些文件。无论任务是手动执行、[计划](./schedules)调度还是[自动化流程](./flows)触发，都会记录在这里。

## 日志列表

![](/images/orbitcontrol/user-guide/executions-page-list.png)

列表以表格展示，支持按任务名称搜索、按站点筛选和分页：

| 列 | 说明 |
|----|------|
| 任务名称 | 执行时的任务名快照 |
| 设备名称 | 执行设备名快照 |
| 站点 | 所属站点 |
| 运行时间 | 计划/触发的时间 |
| 结束时间 | 实际完成时间 |
| 附件上传 | 媒体文件上传进度（已传/总数） |

点击任意一行进入**执行详情**。

## 执行详情

详情页分为三个页签：

![](/images/orbitcontrol/user-guide/executions-page-detail.png)

### 概览

执行结果摘要，包括：

- **运行统计**：执行时长、航点进度等
- **电池/电量**：执行期间电量变化
- **设备信息**：执行设备的信息
- **任务概要**：任务配置快照

### 回放

执行期间设备记录的数据包（MCAP），加载后可逐帧回放设备运行过程。该执行未生成 MCAP 文件时会提示。

![](/images/orbitcontrol/user-guide/executions-page-playback.gif)

### 媒体文件

执行期间设备拍摄的照片和录像，上传完成后集中展示。相关媒体也可在 [画廊](./gallery) 中浏览。
