# 标注

「标注」在地图上绘制点、线、多边形，用于标记现场的关键位置和区域（如充电桩、危险区域、巡检点位）。标注归属**地图**：每张地图维护自己的标注，随地图显示。

标注是设备作业的重要辅助：任务航点可参考标注位置，操作中也可通过标注快速导航。

## 进入标注管理

1. 顶部工具栏选择**站点**
2. 选择**地图**（带地球图标的是世界地图类地图）

![](/images/orbitcontrol/user-guide/annotations-page-main.png)

## 绘制标注

地图左侧提供绘制工具：

| 工具 | 说明 |
|------|------|
| **绘制点** | 在地图上点击放置一个点标注 |
| **绘制线** | 依次点击绘制折线，双击（或确认）结束 |
| **绘制多边形** | 依次点击绘制多边形，闭合后结束 |

![](/images/orbitcontrol/user-guide/annotations-toolbar-draw.png){.w-1/2}

绘制完成后，弹出标注属性表单：

- **名称**：标注名称
- **描述**：可选补充说明
- **颜色**：标注的显示颜色
- **分组**：将标注归入分组，便于批量管理

保存后标注显示在地图上。点击已有标注可重新编辑或**删除**。

## 分组管理

点击工具栏「分组列表」打开右侧分组面板：

- 点击 ![](/icons/plus.svg) 新建分组（支持嵌套子分组）
- 分组用于归类标注，例如「充电设施」「警戒区域」

## 在设备控制中使用标注

在 [设备控制](./live-control) 页面，地图上的标注可以直接用于导航：点击标注，将设备导航至标注位置。
