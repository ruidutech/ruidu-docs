# 自动化流程

「自动化流程」让平台在特定事件发生时**自动响应**：定义触发条件（警报/告警）和响应动作（前往现场/执行任务），无需人工值守。典型场景：周界入侵自动响应——设备自动前往警报位置巡查。

## 流程列表

![](/images/orbitcontrol/user-guide/flows-page-list.png)

列表展示所有流程，支持按名称或描述搜索，点击进入编辑。

## 新建流程

![](/images/orbitcontrol/user-guide/flows-form-new.gif)

流程由三部分组成：**触发**、**条件**、**动作**。

### 第一步：选择触发类型

| 触发类型 | 说明 |
|----------|------|
| **安防警报** | 场所级警报触发（来自警报系统），如消防占道、门禁异常、人员倒地 |
| **设备告警** | 设备自身告警触发，如低电量、信号丢失、GPS 信号丢失、突破地理围栏 |

- 安防警报可进一步**过滤警报类型**（多选，满足任一即触发；不选则不限类型）
- 设备告警需选择具体的**告警类型**

### 第二步：选择站点与设备

先选站点，再选执行响应的设备。

::: tip
「设备告警」触发的流程**无需选择执行设备**：产生告警的设备自动执行响应任务。
:::

### 第三步：配置动作

| 动作 | 说明 |
|------|------|
| **前往警报位置** | 设备自动导航到警报发生的地理位置，可设置到达后的巡逻半径（留空则不限） |
| **执行任务** | 设备自动执行指定任务，从站点任务列表中选择 |

每个流程带 60 秒冷却时间：冷却期内同一流程不会重复触发。

## 执行日志

流程每次触发都会记录执行日志。在流程列表进入流程详情，查看「执行日志」：

![](/images/orbitcontrol/user-guide/flows-page-logs.png){.w-1/2}

日志展示每次触发的时间、触发详情和执行结果。
