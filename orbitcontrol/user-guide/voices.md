# 语音库

「语音库」由文字生成语音文件并分发到设备：任务航点的「语音播报」动作按 **key** 引用这里的语音，设备到达航点后现场播报。适用于安全提示、警示喊话等场景。

## 语音列表

![](/images/orbitcontrol/user-guide/voices-page-list.png)

列表展示每条语音的名称、key 和播报文本，支持**试听**和**编辑**。

## 生成语音

点击「生成语音」打开对话框：

![](/images/orbitcontrol/user-guide/voices-dialog-generate.png){.w-1/2}

| 字段 | 说明 | 示例 |
|------|------|------|
| key | 语音的唯一标识，任务中按此引用 | `obstacle_warn` |
| 名称 | 便于识别的名称 | 被阻挡提醒 |
| 播报文本 | 实际播报的内容 | 请注意，前方有车辆作业，请绕行 |
| 音色 | 可选，合成语音的音色 | — |

生成后语音文件自动分发到设备。

::: tip
语音库为空时，任务编辑器中的「语音播报」动作会提示先到语音库生成。也可以在播报动作中改用「实时文本」，由设备端 TTS 直接合成（需设备支持）。
:::
