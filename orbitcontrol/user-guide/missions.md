# 任务

「任务」定义设备的一次完整作业：设备按顺序经过一系列**航点**，并在航点上执行**动作**（拍照、录像、播报语音等）。任务创建后，可在 [设备控制](./live-control) 中手动执行，也可以交给 [计划](./schedules) 定时调度或 [自动化流程](./flows) 触发执行。

平台支持两类任务：

| 类型 | 说明 | 状态 |
|------|------|------|
| **路径任务** | 逐个航点依次巡行，每个航点可配置动作 | 可用 |
| **网格任务** | 覆盖式网格巡行（适用于区域覆盖拍摄等场景） | 建设中 |

## 任务列表

左侧为任务列表，支持按名称搜索、按站点筛选。点击右上角 ![](/icons/circle-plus.svg) 选择任务类型开始创建。

![](/images/orbitcontrol/user-guide/missions-page-list.png)

任务卡片显示任务类型图标、名称、所属站点和最后更新时间，可进行**编辑**和**删除**（删除需二次确认）。

## 创建路径任务

::: warning
新任务需**先保存基础信息**（名称、站点、任务配置），再进入编辑绘制航点。
:::

### 第一步：保存基础信息

点击「路径任务」进入编辑器，填写：

| 字段 | 说明 |
|------|------|
| 任务名称 | 20 个字以内 |
| 选择站点 | 任务归属的站点，决定可用的地图 |
| 巡航速度 | 设备巡行的速度（m/s），最小 1 |
| 结束动作 | 任务完成后的行为：**返航** / **原地等待** / **回到第一个航点** |

![](/images/orbitcontrol/user-guide/missions-form-path.png){.w-1/2}

### 第二步：绘制航点

保存后从任务列表重新进入编辑，切换到「路径配置」页签，点击 ![](/icons/plus.svg) 进入加点模式，在地图上依次点击放置航点：

- 点击地图上的**路网节点**可直接吸附节点位置
- 点选完成后点击「结束」退出加点模式
- 通过 `‹ ›` 按钮（或点击地图上的航点）在航点间切换，当前航点高亮
- 工具栏还提供**定位**（地图视角跳到当前航点）和**删除**（移除当前航点）

站点有多张地图时，可通过地图控件切换地图，分别在不同地图上添加航点（跨地图任务）；选中其他地图上的航点时会自动切换过去。

### 航点动作

选中航点后，在「执行动作」中添加该航点到达后执行的动作，动作按顺序执行，可拖拽调整顺序：

| 动作 | 配置项 |
|------|--------|
| **等待** | 等待时长（秒），0 表示无限等待 |
| **云台记忆** | 云台姿态（Yaw/Pitch/Zoom/Focus）；可从在线设备**一键读取当前云台状态** |
| **拍照** | 拍照数量（1~10 张）、拍照间隔（秒，0 表示仅拍 1 张） |
| **录像** | 录制时长（秒） |
| **语音播报** | 来源二选一：**语音库**（引用[语音库](./voices)中生成的语音）或**实时文本**（设备端 TTS 播报，需设备支持）；可设置音量（0-100） |
| **充电** | 目标电量（达到后自动停止充电），或勾选持续充电 |

![](/images/orbitcontrol/user-guide/missions-form-path-waypoint.gif)

::: tip
「云台记忆」的读取功能：点击动作卡片上的读取按钮，选择站点内在线设备，平台读取该设备当前云台姿态并填入动作。
:::
