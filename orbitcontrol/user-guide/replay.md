# 回放

「回放」查看设备多摄像头的历史录像同步回放，用于事后追溯设备执行过程。

![](/images/orbitcontrol/user-guide/replay-page-main.png)

## 使用步骤

1. 选择**日期**：日历面板中标出的日期有录像资源
2. 选择**设备**：查看该设备当日的录像
3. 四分屏同步回放设备的**云台（前置位）/ 左 / 右 / 后**四路摄像头

## 播放控制

- 底部**时间轴**拖动定位到任意时刻，四路画面同步跳转
- 点击任一路画面可**放大显示**单路全屏，点击「返回四分屏」恢复

![](/images/orbitcontrol/user-guide/replay-flow-playback.gif)

::: tip
所选日期下没有视频资源时，尝试选择其他日期或设备。录像由设备端上传，执行结束后需要一定的上传时间。
:::
