# 角色与权限

平台权限以**企业**为单位管理。每个用户在企业中拥有一个角色，角色决定了可使用的功能。

## 企业角色

| 角色 | 说明 | 如何获得 |
|------|------|----------|
| **所有者** | 企业的一切权限，包括企业设置、成员管理、转让企业 | 创建企业的用户自动成为所有者，每个企业有且仅有一个所有者 |
| **管理员** | 企业内的管理与运维权限，可管理成员和各项资源 | 通过[所有权转让](./tenant)或开放 API 调整（界面直接调整角色的入口建设中） |
| **成员** | 日常操作权限，可操控设备、编排任务、查看数据 | 通过邀请码加入企业后默认为成员 |

## 权限一览

| 功能 | 成员 | 管理员 | 所有者 |
|------|:----:|:------:|:------:|
| 实况（设备控制、视频墙） | ✅ | ✅ | ✅ |
| 任务规划（任务、计划、流程、标注、路网） | ✅ | ✅ | ✅ |
| 数据中心（语音库、日志、画廊、回放） | ✅ | ✅ | ✅ |
| 管理（站点、设备、地图、用户、应用） | ❌ | ✅ | ✅ |
| 企业管理（成员与角色、邀请、入驻审批） | ❌ | ✅ | ✅ |
| 企业信息设置、转让企业、移除成员 | ❌ | 部分 | ✅ |

::: warning
权限由服务端强制校验。即使通过 URL 直接访问管理页面，无权限的操作也会被拒绝。
:::

## 站点操作人员

除了企业级角色，站点还可以单独分配**操作人员**：只有被分配到站点的用户，才能操作该站点下的设备。在 [站点管理](./sites) 中编辑站点时设置。

## 账号状态

管理员可以在 [用户管理](./users) 中禁用或启用用户账号，被禁用的账号无法登录。当前登录账号不可自我禁用。
