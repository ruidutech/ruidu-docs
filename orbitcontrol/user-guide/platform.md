# 平台总览

登录并进入企业后，平台整体布局分为三部分：**顶部栏**、**左侧导航栏**和**主内容区**（大部分页面以地图为底）。

![](/images/orbitcontrol/user-guide/platform-page-layout.png)

## 左侧导航

导航栏按功能域分为五组，与本手册的章节一一对应：

| 分组 | 页面 | 说明 |
|------|------|------|
| **实况** | 设备控制、视频墙 | 实时操控与监控 |
| **任务规划** | 任务、计划、自动化流程、标注、路网 | 任务的编排与调度 |
| **数据中心** | 语音库、运行日志、画廊、回放 | 运行产出与历史数据 |
| **区域** | 电子围栏、禁飞区 | 区域限制（随无人机支持陆续开放） |
| **管理** | 站点、设备、地图、用户、组织、应用、企业 | 平台配置（需管理员权限） |

点击导航栏顶部按钮可折叠/展开导航栏，为主内容区腾出空间。

## 顶部栏

从左到右依次为：

- **Logo**：点击回到首页（设备控制）
- **主题切换**：在亮色/暗色主题间切换
- **通知**：查看平台通知，详见下文
- **用户菜单**：账户管理、切换企业、退出登录

### 通知

![](/images/orbitcontrol/user-guide/platform-menu-notification.png){.w-1/2}

通知按时间倒序、以日期分组展示，每条通知包含来源、标题和内容：

- 左侧色条表示级别：**绿色**成功、**红色**失败、**蓝色**普通
- 顶部可按「所有 / 失败 / 成功」筛选
- 未读通知在铃铛图标上显示数量角标；单条通知悬停后可标记已读，也可点击「全部已读」一键清除

### 用户菜单

用户菜单展示当前登录用户与所属企业（含你在该企业中的角色），提供以下功能：

| 菜单项 | 说明 |
|--------|------|
| **账户管理** | 修改个人信息与界面语言 |
| **切换企业** | 一个账号可加入多个企业，在此切换当前操作的企业 |
| **创建或加入企业** | 新建企业或使用邀请码申请加入 |
| **企业管理** | 仅所有者/管理员可见，进入企业管理页面 |
| **退出登录** | 退出当前账号 |
