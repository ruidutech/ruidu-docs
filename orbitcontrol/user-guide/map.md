# 地图操作

平台的大部分页面（设备控制、任务、标注、路网等）以地图为工作底板。本章说明地图的通用概念与操作，各业务页面不再重复。

## 世界地图与本地地图

| 地图 | 说明 |
|------|------|
| **世界地图** | 在线卫星/街道底图，按经纬度展示全局位置 |
| **本地地图** | 设备建图产出的场地内部地图 |

在哪种地图上作业没有强制限制，取决于设备所处的环境：未建图或室外场景在世界地图上作业，场地内完成建图后可切换到本地地图。

点击地图左上角的「选择地图」按钮可切换当前显示的地图：列表展示站点下可用的地图，带地球图标的是世界地图类地图，其余为本地地图。

本地地图由设备建图产出，建图与管理见 [地图管理](./maps)。

## 各功能的地图使用

| 功能 | 地图使用 | 详见 |
|------|----------|------|
| 设备控制 | 自动加载设备所属站点的地图，站点没有地图时显示世界地图 | [设备控制](./live-control) |
| 任务 | 任务归属站点，可在站点的多张地图上分别绘制航点（跨地图任务） | [任务](./missions) |
| 标注 | 标注归属地图，每张地图维护自己的标注 | [标注](./annotations) |
| 路网 | 路网归属地图，每张地图维护自己的路网 | [路网](./route-graph) |

## 基础操作

| 操作 | 方式 |
|------|------|
| 缩放 | 滚轮，或右侧控件 ![](/icons/plus.svg) 放大、![](/icons/minus.svg) 缩小 |
| 平移 | 按住鼠标左键拖动 |
| 重置视图 | 右侧控件 ![](/icons/maximize.svg)，回到当前地图的完整范围 |
