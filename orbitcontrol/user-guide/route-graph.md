# 路网

「路网」描述设备在地图上的可行驶路径：由**节点**（路经点、充电点、电梯点、停靠点）、**边**（路径连线）和**区域**组成。建好路网后：

- [任务](./missions) 编辑时可点击路网节点直接取点
- [设备控制](./live-control) 页可点击节点让设备前往
- 设备导航沿路网行驶，路线更可控

路网归属地图，每张地图维护自己的路网。

## 页面布局

顶部工具栏从左到右：站点选择、地图选择、**继承**、**录制**、**显示设备**、版本指示、**保存**。

![](/images/orbitcontrol/user-guide/route-graph-page-main.png)

- **版本指示**：显示已保存的版本号；地图尚无路网时提示「该地图尚无路网」
- **未保存**：编辑后有未保存的修改时出现，点击「保存」提交为新版本（版本号 +1）

## 手动编辑

### 放置节点

进入加点模式后点击地图放置节点，节点分四类：

| 节点类型 | 说明 |
|----------|------|
| 路经点 | 路径上的普通经过点（显示序号） |
| 充电点 | 充电桩位置 |
| 电梯点 | 电梯位置 |
| 停靠点 | 设备停靠/待命位置 |

选中节点可修改类型和朝向。

::: tip
开启「显示设备」后，地图上显示在线设备；编辑中点击设备图标，可直接取设备当前位置和朝向作为节点位置。
:::

### 连线路径

进入连线路模式后依次点击地图，生成**路经点**并自动连线；按 `Enter` 结束当前路径。

- 选中一条边，中点出现临时点，点击可在中间**插入路经点**（边分裂为两条）
- 贝塞尔边显示两个控制点手柄，拖拽调整弧形
- 拖拽路经点支持**吸附**：靠近其他节点时自动吸附对齐；吸附到另一个路经点则二者合并

### 绘制区域

支持多边形区域（依次点击顶点，`Enter` 闭合）和圆形区域（点击圆心，再点击确定半径），选中后可整体拖动或调整顶点/半径。

## 路网录制

手动逐点绘制效率低时，用**录制**方式生成路网：遥控设备实际走一遍，轨迹自动简化为节点和边，并入路网草稿。

1. 点击「录制」，选择站点内的在线设备
2. 设备切换到手动模式，页面出现 FPV 面板和摇杆——遥控行驶一遍目标路径
3. 行驶完成后点击「停止并生成草稿」，轨迹简化后并入当前路网

::: warning
在世界地图上录制时，请确保设备处于 **RTK 固定解**状态，否则轨迹精度不足。
:::

## 从已有地图继承

地图更新（如重新建图）后，旧路网可以通过**继承**迁移到新地图：

1. 在新地图上放置**至少 2 个节点**作为锚点（位置与旧地图上对应）
2. 点击「继承」，选择来源地图
3. 平台自动配对锚点并对齐旧路网，叠加显示在当前地图上供确认
4. 对照叠加效果确认无误后合并；不匹配的锚点可手动微调
