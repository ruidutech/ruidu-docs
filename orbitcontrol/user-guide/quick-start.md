# 快速开始

本章带你从零开始完成账号注册、进入企业，直到第一次操控设备。

## 注册账号

打开平台地址，进入登录页，点击「立即注册」。

![](/images/orbitcontrol/user-guide/auth-page-login.png){.w-1/2}

填写用户名、邮箱和密码完成注册。用户名用于登录系统，密码至少 6 个字符。

![](/images/orbitcontrol/user-guide/auth-page-register.png){.w-1/2}

## 进入企业

平台以**企业**为隔离单位：站点、设备、任务等资源都属于某个企业，用户必须加入企业后才能使用平台功能。

注册成功后登录，如果账号尚未加入任何企业，平台会自动进入「开始使用」向导：

- **创建新企业**：适合第一个使用平台的用户，创建后自动成为该企业的**所有者**
- **加入现有企业**：请联系企业管理员获取**邀请码**，在「申请加入企业」页面输入 8 位邀请码并提交，等待管理员审核通过

![](/images/orbitcontrol/user-guide/tenant-page-guide.png)

创建新企业时需要填写：

| 字段 | 说明 |
|------|------|
| 企业名称 | 企业的显示名称，例如：睿度智能科技 |
| 企业代码 | 企业唯一标识，小写字母、数字、连字符和下划线，**创建后不可修改** |

![](/images/orbitcontrol/user-guide/tenant-page-new.png)

## 首次配置

进入平台后，按以下顺序完成基础配置，之后就可以开始操控设备了：

1. **新建站点** — 圈定设备的工作范围，参见 [站点管理](./sites)
2. **注册设备** — 将设备接入平台并分配到站点，参见 [设备管理](./devices)
3. **建立地图** — 遥控设备建图或导入已有地图，参见 [地图管理](./maps)
4. **绘制路网**（可选）— 规划设备的行驶路网，参见 [路网](./route-graph)
5. **编排任务** — 创建路径任务或网格任务，参见 [任务](./missions)

配置完成后，进入「实况 → 设备控制」即可开始操控，参见 [设备控制](./live-control)。
