# 地图管理

「地图管理」维护站点的地图：遥控设备**建图**、编辑、重命名、删除、同步到设备。地图是任务规划、标注、路网的基础，参见 [地图操作](./map)。

## 地图列表

选择站点后，地图选择器列出该站点的全部地图（含版本号），底部「**新建地图**」进入建图流程。选中地图后，工具栏提供操作按钮：

| 按钮 | 说明 |
|------|------|
| **编辑** | 打开图片编辑器，修饰地图底图（裁剪、标注等） |
| **更名** | 修改地图名称 |
| **重建** | 用现有地图名称重新建图（旧图数据保留） |
| **删除** | 从平台删除该地图 |
| **同步** | 将站点地图下发到站点内所有设备 |

![](/images/orbitcontrol/user-guide/mgr-maps-page-list.png)

## 新建地图（遥控建图）

建图通过遥控设备实地走一遍完成，分四步：

![](/images/orbitcontrol/user-guide/mgr-maps-dialog-mapping.gif)

1. **选择设备**：选择站点内用于建图的在线设备
2. **确认切换建图模式**：设备将切换至建图模式，此操作会**中断设备当前正在执行的任务**，切换过程约需 5-6 秒
3. **切换中**：等待设备完成模式切换
4. **建图**：通过 FPV 面板和摇杆遥控设备，**缓慢移动**遍历场地，页面实时显示建图进度帧；完成后点击「保存」，输入地图名称

::: warning
建图会中断设备当前任务，请选择设备空闲时进行。
:::

## 删除地图

![](/images/orbitcontrol/user-guide/mgr-maps-dialog-delete.png){.w-1/2}

删除地图会：

- 通知站点内所有设备**清理本地地图文件**
- 从平台删除该地图（版本数据保留用于审计）

## 同步地图

地图更新（建图、编辑）后，点击「同步」将站点最新地图下发到站点内所有设备，保证设备本地地图与平台一致。
