# 站点管理

`站点` 是设备和任务的组织单元：一个站点可以小到一个园区，大到一片行政区域。`设备`、`任务`、`地图` 都归属站点，用户也按站点分配操作权限。

## 站点列表

左侧为站点列表，支持搜索和排序（按名称/创建时间/更新时间，升序/降序）。点击右上角 ![](/icons/circle-plus.svg) 新建站点。

![](/images/orbitcontrol/user-guide/mgr-sites-page-list.png)

站点卡片显示名称、关联统计（设备/任务/用户）和最后更新时间，可**编辑**和**删除**（删除需二次确认）。

## 新建/编辑站点

![](/images/orbitcontrol/user-guide/mgr-sites-dialog-edit.png){.w-1/2}

站点表单分四部分：

### 基本信息

| 字段 | 说明 |
|------|------|
| 站点名称 | 20 个字以内 |

### 位置

点击 ![](/icons/crosshair.svg) 后在地图上点选站点位置，选定的经纬度显示在下方。站点位置用于地图快速定位。

### 分配设备

点击 ![](/icons/plus.svg) 添加设备到站点。**一个设备只能分配到一个站点**；已分配给其他站点的设备不可再选。

### 分配成员

为站点分配**操作人员**：只有被分配到站点的成员才能操作该站点的设备（参见 [角色与权限](./roles)）。点击 ![](/icons/plus.svg) 从企业成员中选择，点击 ![](/icons/trash-2.svg) 移除。
