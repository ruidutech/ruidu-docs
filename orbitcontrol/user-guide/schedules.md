# 计划

「计划」让任务按时间表自动执行：为一个任务指定执行设备和重复规则，平台按规则生成执行实例，无需人工触发。

## 日历视图

计划以日历形式展示，支持三种视图：

- **Day**：单日时间轴，按小时排列
- **Week**：一周七列时间轴
- **Month**：整月网格

![](/images/orbitcontrol/user-guide/schedules-page-list.png)

- 点击「今日」快速回到当前日期，左右箭头前后翻页，点击日期标题可从日历面板直接选日期
- 日历上的色块是该时间段的**计划执行实例**，点击任一实例即可打开其所属计划进行编辑

## 新建计划

点击「新建计划」打开对话框：

![](/images/orbitcontrol/user-guide/schedules-dialog-edit.png){.w-1/2}

| 字段 | 说明 |
|------|------|
| 标题 | 容易区分和记忆的标题 |
| 设备 | 先选站点，再选该站点下执行计划的设备 |
| 任务 | 选择站点下的任务 |
| 开始时间 | 计划首次执行的时间 |
| 重复 | 执行频率，见下表 |
| 结束时间 | 可选，超过该时间后计划不再执行 |
| 描述 | 可选 |

重复类型：

| 类型 | 说明 |
|------|------|
| 永不 | 只执行一次 |
| 按天 / 按周 / 按月 / 按年 | 按所选周期重复 |
| 自定义 | 自定义间隔 |

选择重复后，还需填写**间隔值**（每 N 天）。

## 编辑与删除

点击日历上的执行实例进入计划编辑，修改后保存生效。

- **删除**：编辑对话框左下角「删除」→ 确认后删除该计划及其**未来的执行实例**；已执行的历史记录保留，可在 [运行日志](./executions) 中查看
