# 设备管理

「设备管理」维护设备台账：注册设备、分配站点、查看设备详情。注意与 [设备控制](./live-control) 区分——设备管理面向管理员，管理设备的「档案」；设备控制面向操作员，负责实时操控。

## 设备列表

![](/images/orbitcontrol/user-guide/mgr-devices-page-list.png)

表格展示所有设备，支持按名称搜索、按站点筛选和分页：

| 列 | 说明 |
|----|------|
| 设备名称 | 点击进入设备详情 |
| 设备类型 | 通用飞行器 / 地面无人车 / 水面无人船 / 云台 / 智能从属设备 |
| 站点 | 所属站点（未分配显示 `-`） |
| 设备序列号 | 设备唯一标识 |
| 硬件版本 | 设备上报的硬件版本 |
| 注册状态 | 未注册 / 已注册 / 已拒绝 |

## 添加设备

点击「添加设备」打开对话框：

![](/images/orbitcontrol/user-guide/mgr-devices-dialog-register.png){.w-1/2}

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 设备序列号 | ✅ | 设备的唯一标识，印于设备机身或随附文档 |
| 设备类型 | ✅ | 从类型列表选择 |
| 设备名称 | | 留空则使用序列号作为名称 |
| 所属站点 | | 可以稍后分配 |

设备添加后，设备端使用分配的连接信息接入平台，上线后状态变为**已注册**。

## 设备详情

点击设备行进入详情页，顶部可**编辑设备名称**，下方页签：

![](/images/orbitcontrol/user-guide/mgr-devices-page-detail.png)

| 页签 | 内容 |
|------|------|
| **概览** | 设备基本信息、传感器配置、能力参数（最大速度、电池容量等） |
| **诊断** | 设备的诊断信息，用于排查故障 |
| **运行日志** | 该设备的执行历史 |
| **固件** | 固件版本信息与升级选项 |
| **设置** | **MQTT 连接信息**（服务器、端口、用户名、密码），供设备端配置接入 |
