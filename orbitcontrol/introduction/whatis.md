# 什么是 OrbitControl

OrbitControl 是睿度智能推出的机器人云端管控平台，将分散在各作业现场的移动设备统一接入云端，提供地图构建、路网规划、任务编排、远程操控与数据回放能力，让操作员在一块屏幕前完成设备的日常作业。

![](/images/orbitcontrol/user-guide/platform-page-layout.png)

## 核心概念

平台以四个层级组织资源：

```mermaid
flowchart LR
    T[企业 Tenant] --> S[站点 Site] --> D[设备 Device] --> M[任务 Mission]
```

| 概念 | 说明 |
|------|------|
| **企业** | 资源隔离与协作的单位，站点、设备、任务等资源都归属企业；一个账号可加入多个企业 |
| **站点** | 设备的工作范围（地理围栏），设备注册后分配到具体站点 |
| **设备** | 接入平台的机器人本体，通过 MQTT 协议与平台双向通信 |
| **任务** | 设备执行的工作单元（路径任务、网格任务等），可手动触发、按计划调度或由自动化流程触发 |

## 平台能力总览

| 能力域 | 包含功能 | 解决的问题 |
|--------|----------|------------|
| **实况** | 设备控制、视频墙 | 远程实时操控与多路监控 |
| **任务规划** | 任务、计划、自动化流程、标注、路网 | 作业的编排、调度与现场要素管理 |
| **数据中心** | 语音库、运行日志、画廊、回放 | 作业产出与执行过程的留存回溯 |
| **管理** | 站点、设备、地图、用户、应用、企业 | 平台资源的配置与权限管理 |

## 适用场景

- **多站点集中管控**：一个企业下的多个作业现场统一纳管，操作员按站点切换作业范围
- **例行巡检类作业**：将巡检路线编排为任务，交给计划或自动化流程定时执行，人工只在异常时介入
- **危险/恶劣环境替代人工作业**：操作员在远端通过实时画面与控制面板完成现场作业
- **作业过程留档**：执行日志、现场照片与录屏自动归档，用于追溯与汇报
